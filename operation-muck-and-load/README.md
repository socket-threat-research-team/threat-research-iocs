# Operation Muck and Load

This directory contains public indicators and infrastructure appendices associated with Socket Threat Research’s Operation Muck and Load report.

Report: [Socket blog URL]

## Files

- `operation-muck-and-load-github-infrastructure.txt` - GitHub accounts and repositories associated with the analyzed infrastructure cluster

## Notes

The GitHub infrastructure list is intentionally conservative. Repository and account entries describe infrastructure-cluster membership and should not be read as a claim that every listed repository contains malware.
